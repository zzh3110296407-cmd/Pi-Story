All four structural classifications are confirmed by the completed delegated AI r2 review. Every variant has its own BranchEntry sequence: DS09 prior bible/canon, an actual author message, eight exact-quoted ledger requirements, outline with measured target words, current chapter intent, author intent/current focus, an effective bible update, then the current draft. Basis, digest and current draft are validated using frozen P1 createDraft, schemas and foldBranch. New review-context bible attributes are original explicit fixture design, not inferred requirements from a public benchmark.

Characterisation reverses a fixed handedness attribute; factual details retain the correct narrated count and append an incompatible total for that same count; narrative style changes the full chapter mode in four cases and adds removable framing in two; timeline/plot contradicts the supplied life/death chronology outside dreams/recalls; world/setting violates the explicit physical rule; ledger violation kills a person explicitly required to survive. A defect can have several direct consequences but is counted once by its designed cause. Overlapping category descriptions are matched semantically, not by exact taxonomy strings alone. Each record includes actual LF line numbers, before/after text, multi-span sites, explicit source and justification. Injection order is explicit per variant. The four rewrites are applied first and a paired local timeline defect is then appended. Other variants use local edits followed by any removable local framing. Full style spans end before the separately counted timeline append.

The original chapters are AI-written by this dataset session, not by the project writer. unplanned.json records known incidental issues separately and does not claim completeness. Zero-injection controls are not guaranteed flawless. Newly validated baseline issues belong in additive judgments so valid discoveries are not incorrectly counted as false positives.

No model calls, execution role rules, scoring scripts or acceptance run artifacts were used. Freeze only after DS09 source is frozen and every acceptance injection has author review.
