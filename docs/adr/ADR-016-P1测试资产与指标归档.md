状态：已修订。初次采用与修订日期：2026-10-28。依据16 §6–§8、18第2版；作者要求测试内容随仓库保存，替代原仓库外存放决定。结果权限仅限方案目录测试结果/P1及指标总表中的P1行。

测试代码与评分器入库，测试集在 `story/testing/datasets/<名称>/vN`，提交即冻结。清单登记逐文件SHA-256、来源、许可和划分；项目检查核对摘要、清单外文件与Git中已提交版本的原地改动。标注说明区分AI标注、人工核对与作者复核。缺失或不一致即失败，不跳过、不运行模型。修订发布新版本，不覆写冻结版。

运行记录在 `story/testing/runs/P1/<套件>/<UTC时间>-<提交短号>`。判断dirty时排除 `story/testing/runs/`；dirty运行只留本机、不提交、不作证据。运行结束后提交Vitest JSON、原始观察、日志、清单和指标，提交后不覆写。评分器只读取测试输出与金标，不读取业务源码；H01覆盖生成例外地读取测试名称。比例附95% Wilson区间，人工状态另列。

`story/testing/.gitattributes` 使用 `* -text`，原字节及摘要不变；Biome、Vitest发现和类型检查排除本目录。`private/` 被忽略，不允许再分发或含个人信息的材料不进入公开区域；公开区域检查环境文件、认证字段与密钥特征，诊断不输出匹配值。迁移的6个v1仍是参考，来源许可记录原样保留，本地导入不新增再分发许可。

测试根默认按工具文件位置解析。`PI_STORY_TEST_ROOT` 只覆盖测试集根；`PI_STORY_RUNS_DIR` 独立覆盖运行根，供导出副本写回主仓库；`record()`只能写到运行根的子目录。`PI_STORY_WORK_DIR` 默认 `D:/开源/test/pi-Story/p1`，供依赖、缓存及临时文件使用，工作区不作为测试内容的权威位置。

性能原始毫秒样本保存在raw观察中。2026-10-29作者终审批准DD13：H14以5次原始中位数判断≤1秒；100毫秒向上取整仅作displayValue展示。P1-R中两次H14分别满足门槛，H14-O仅观察变化，其余确定性指标逐字段严格一致。比较入口为run-suite.mjs --compare，不再用展示值相同证明性能复现。
