# ADR-005 系统提示与规则装配

日期：2026-10-28。依据：V10 替身和真实 DeepSeek 的请求、system条目和compaction记录。

固定规则、作者意图与进度按sections注入。三轮中首轮记录全部分段，后两轮只记录变化的probe_progress。真实三轮cacheRead分别为256、2176、2176；真实压缩后下一轮固定规则仍在，实际请求没有依赖Skill目录。

决定：主笔规则直接进入固定系统提示分段，角色规则由宿主装配，不依赖已关闭的read/bash按需读Skill。进度只有变化部分进入持久化。

短对话达不到默认压缩保留阈值。替身夹具只在自有D盘运行目录设置keepRecentTokens32，并用进程级-a启用该自有配置；真实SDK夹具使用keepRecentTokens8。两者均实际生成compaction条目。该设置只用于验证压缩边界，不是产品默认值。按实际请求台账，第一次真实夹具失败的3次请求也计入V10费用，最终场景6次，共9次，压缩内部调用同样计入。

V11的上下文编辑为可选优化，不是v1.0正确性前提。
