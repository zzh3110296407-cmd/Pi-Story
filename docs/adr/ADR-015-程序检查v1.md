# ADR-015：程序检查v1

状态：采用，自动测试已验证，作者于2026-10-29终审认可。

依据15附录A.2。正文少于目标20%记客观blocking/structural；低于50%或高于200%另记客观minor/structural。边界值20%、50%、200%不触发对应的严格不等式。两项分别判定，极短正文可以同时产生两条观察。

残留标记包括写手分隔符、三反引号围栏，以及行首可机械识别的“作为AI/写手”“写手说明：”“以下是正文/章节：”。它们产生客观blocking/local，证据为所在行。自然叙述中提到“写手”本身不触发。

段落按正文LF分行定义，做NFC及空白合并；相同段落至少出现两次，且含至少20个汉字或10个非汉字词时记客观major/local，证据包括所有重复行。正文为空由写手解析拒绝。

检查不判断剧情、风格或证据是否在语义上成立。DS05 v2的75个冻结样例已接入自动测试，并保留3章真实素材的观察记录；金标与观察仍待作者复核，P2还需在真实新草稿上验证阈值与提示语识别。H08数值以最终提交的套件记录为准。
