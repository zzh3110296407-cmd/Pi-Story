# ADR-011：网页组件取用范围

日期：2026-10-28。依据：V25；参考提交 `0a53fb55bea101816fa226bb964ae2bed71c343b`。

## 背景与选项

完整 ui-primitives 的清单和 invariant companion 包含 Cordis peer/type import，不能将全包称为无 Cordis。按验证清单允许的替代，只取 Markdown 渲染源码闭包及 clipboard.ts，共17个源文件，保留原MIT全文；不复制工作区包的启动与依赖装配。

## 决定与实测

采用上述最小取用范围。独立 Vite/React 应用在D盘安装精确依赖并构建成功，Edge真实渲染中文章节，13个段落、GFM表格、引用、代码块和中文加粗均通过DOM断言，未出现pageerror。已查看整章截图，标题、正文、表格及结尾可读，无重叠和裁切。

构建保留了大于500kB的chunk警告，入口约921kB、gzip约239kB；语法高亮还产生多个语言chunk。P0没有为消除警告提高阈值或改第三方代码，P6应按实际所需语言和渲染功能评估加载成本。本次只证明能够脱离Cordis独立构建与渲染，不代表网页产品或加载性能已验收。

证据：`D:\开源\test\pi-Story\p0\runs\V25\2026-10-28T11-26-38-601Z\result.json`；同目录保留dependency-inventory.json、安装/构建日志、DOM结果、截图和视觉检查。
