# ADR-006 自动继续与作者控制

日期：2026-10-28。依据：V12、V13、V14、V26；无界面降级见 V15。

agent_before_settle只有continue true不够：末条为assistant且没有排队输入时，Pi拒绝无可运行上下文的继续请求。探针补齐原生合同，返回一条custom_message继续请求及continue true，随后恰好达到3章停止。问作者、预算开关与clear_queue加abort均停止自动继续。

作者控制只经扩展命令写入。伪造修改工具被拒；带参命令及无参预填编辑框均可用。运行中命令立即handled，控制条目可早于当前工具结果写入；普通steer在批次结束后才交给模型。

即时插话的input事件在工具等待期间到达，带source rpc和streamingBehavior steer；探针序号变化后返回INTERJECTED。followUp不增加序号，工具正常完成。故事实现应保留提交前和最终依据检查；这些时序实测不等于已经实现了业务提交与作者控制的共同串行边界。

V01交互终端、V26终端插话仍由作者人工观察。完整入口为p0/scripts/manual-check.ps1的V01与V26。V15打印、JSON、SDK均能运行并在无UI时给出作者不在场的结果。
