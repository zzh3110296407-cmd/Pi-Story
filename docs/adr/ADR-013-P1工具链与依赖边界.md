# ADR-013：P1工具链与依赖边界

状态：采用。日期：2026-10-28。

story独立npm工作区，精确固定TypeScript 7.0.2、Vitest 4.1.11、Biome 2.3.5、TypeBox 1.3.27和Node类型22.19.19。安装禁用生命周期脚本；依赖、缓存和临时文件均在D盘P1测试根，源码只保留锁文件和node_modules目录联接。install-isolated脚本只复制工作区清单，不安装Pi根工作区，不读取密钥环境变量。

check依次运行上游边界、数据表驱动的包依赖扫描、只读Biome、严格NodeNext类型检查。业务代码只用可擦除TypeScript语法。扫描器采用实际安装的TypeScript 7词法接口；core只能静态引用typebox和node:crypto，所有产品源码不能引用测试目录，Pi仅允许三个适配单元使用。Vitest从空的env目录启动，缓存固定在P1测试根，不加载项目.env文件。

P1没有活动GitHub工作流；上游原文件完整归档，后续项目CI另行设计。无Git钩子安装、无根工作区依赖安装。
