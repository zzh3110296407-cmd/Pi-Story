# ADR-003 串行写入

日期：2026-10-28。依据：V04 的实际 RPC 批次及 probe_write 的可见条目记录。

同一助手消息按 write(1)、write(2)、read 发出三个工具调用。执行事件逐个开始与结束，第二个 write 通过 getBranch() 看到了第一个结果。当前固定提交下，原生 sequential 满足这次批内可见性验证。

决定：写入工具声明 executionMode sequential，不为该路径额外维护一份批内权威状态。方案中的批内覆盖层替代在当前验证中没有启用。此结论只针对该固定版本与已测批次；作者命令与提交之间的并发时序仍由 V14 等单独确认。
