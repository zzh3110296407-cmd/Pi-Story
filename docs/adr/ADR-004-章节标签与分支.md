# ADR-004 章节标签与分支

日期：2026-10-28。依据：V05、V06。

V05 的提交批次还包含一个只读工具；turn_end 的标签成功落在批次最后一个工具结果上，get_tree 能读到标签。V06 从第 1 章工具结果锚点移动后不生成摘要，当前分支不含旧分支第 2、3 章。

决定：按提交批次末尾结果设置章节标签，以 navigateTree 且 summarize false 实现当前故事内部的分支；不用 RPC fork 冒充故事分支。

真实 DeepSeek 在一个样本一次运行中接受了 toolResult 后直接 user 的消息顺序，返回 HTTP 200 与正常停止。这验证协议顺序可用，不构成文学质量证据。原分支继续保存在会话文件。
