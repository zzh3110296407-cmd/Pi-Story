# ADR-023：独立 Git 历史与冻结快照

2026-11-03，作者要求移除 Pi 提交历史及上游根目录贡献、发布和开发记录，连接独立仓库 `https://github.com/zzh3110296407-cmd/Pi-Story.git`。

## 决定

在原项目目录初始化新的 Git 元数据，建立一个无父提交的当前工作文件快照。新仓库不设置上游 remote，不导入旧 refs、reflog、提交对象或 alternates。仅配置自己的 origin，本任务不执行推送。全部自有源码、数据集、测试结果、费用、未提交工作内容与执行环境继续保留。

根目录 CONTRIBUTING.md、SECURITY.md、.github/、.pi/、.husky/ 移至仓库外备份；AGENTS.md 仅保留本项目规则。packages/ 原文不改，Pi 包内文档和许可证继续保留；LICENSE、LICENSE.pi、THIRD_PARTY_NOTICES.md 保留。

## 脱离历史的校验

- `story/scripts/baselines/pi.json` 从原 Pi 提交逐文件导出 Git blob ID、模式与路径。边界检查独立比较 HEAD、索引、工作文件与新增路径，不需要 Pi commit 对象；临时真实 Git 用例证明各层违规都会失败。
- `baselines/p3r2-data.json` 从数据冻结提交 bdea40bf3 导出 DS11 v3、DS14 v2 的完整文件清单。P3R2 继续校验当前已提交文件与交付快照完全一致，新增或缺失文件均不接受，不再要求旧数据提交是 HEAD 祖先。
- `baselines/v4-opening.json` 保存从 V4 原文重新计算的开书边界摘要；V5 开书继承比较继续使用同样范围和 SHA-256。V5.json、正式输出与旧认可记录不改写、不重新冻结。
- Pi 的新构建在 exec/pi-upstream.git 按需浅取单个固定提交用于源码归档；这些第三方构建对象不会进入本仓库。已准备好的 Pi 构建不重建。
- 凭据扫描的已知 Pi 测试夹具仍要求全文 Git blob 匹配固定清单，不能用任意相似词形豁免。
