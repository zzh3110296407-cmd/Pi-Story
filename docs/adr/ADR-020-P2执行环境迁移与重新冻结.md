# ADR-020 P2执行环境迁移与重新冻结

日期：2026-10-30。依据：作者明确要求在 `D:\AI\Story Dome\Story\pi-Story\story\testing\exec` 构建执行环境。

## 位置与边界

Pi构建、Story依赖、缓存、临时文件和运行中会话改用 `story/testing/exec/`。数据集仍在 `story/testing/datasets/`，公开证据仍在 `story/testing/runs/`；不改数据集或人工判定。

项目忽略该执行目录，`story/node_modules` 指向其中的runtime。Pi的file依赖只变更位置，不变更版本；安装使用钉住的锁文件及 `--ignore-scripts`。上游 `packages/` 不修改。准备、安装和测量脚本的默认工作区均改为项目目录，不再依赖旧D盘测试根。

公开测试资产检查仅排除测试根直接下的 `exec/`，与既有 `private/` 的职责相同；嵌套在公开运行中的同名目录仍须检查。新回归先复现 `exec/.env` 被误当公开资产拒绝，再验证根执行目录排除、公开运行内同名目录仍被拒绝。P2-Z仍扫描仓库及整个执行环境，未缩小最终密钥扫描范围。

Pi源码由原固定提交 `b06c1f2cf1dea6af8748ddeee18c23587d2cb7c6` 导出，tar摘要与原构建相同。原工作区被清空，完整原模型目录未保存，因此不能声称全部环境字节相同。

实际使用的Deepseek模型、价格和兼容参数逐字节不变，四份规则、提示模板、温度、low及输出上限不变。恢复后的完整43文件快照（含manifest）已归档到 `story/testing/runs/P2/P2-ENV/20261030-author-workspace/raw/model-catalog.jsonl.gz`，各行保留文件名、原文和SHA-256。environment.json记录完整构建与来源，后续可据此离线恢复，无需重新抓取在线目录。
