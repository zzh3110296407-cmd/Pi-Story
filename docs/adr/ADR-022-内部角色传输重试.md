# ADR-022 内部角色传输重试

日期：2026-11-01。状态：已实施（27 S1，11 U7）；正式V4验收待运行。

## 问题

P2的传输中断直接结束内部角色调用。执行方案27要求一次自动恢复，同时保留每次实际调用的独立费用和输入证据，取消或余额拒绝不得触发后续派发。

## 决定

ModelPort归类transport/rejected/fatal/aborted，core CallSession只对transport等待后再尝试一次。429按Retry-After、最多10秒，其余2秒；等待受AbortSignal控制。格式修复保持原路径，不与传输重试合并。

每次尝试独立预留、started检查点、结算、completed检查点及CallRecord。新记录id取预留编号，重试的retryOf指向旧id，旧历史可缺省。失败没有用量时保留预留，完成后才取消则保留实际用量但取消工作流。重试重新检查预算和perChapterCalls。14次逻辑调用的中断保守上限变为28次。

内部PiModelPort关闭提供方隐藏重试并锁定致命拒绝；主笔自己的重试仍由固定Pi处理，扩展不另加一层。未改core领域校验、写手/编辑/记录员规则与设置。

## 验证与影响

故障测试覆盖流中断、连接错误、超时、5xx、429、拒绝、取消、预算、格式修复；实际core在写手重试后成功提交，所有尝试都出现在details.calls中。取消分类曾在P1回归暴露，修复后回归通过，原失败记录保留于P3-S1。重试增加最坏调用数与保守预留，费用观察应把恢复收益与重试费用分别列出。
