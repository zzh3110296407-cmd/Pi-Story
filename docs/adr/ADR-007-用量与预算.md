# ADR-007 用量与预算

日期：2026-10-28。依据：V16、V17、V18、V27，以及V12的预算派发回归。

工具内部调用的usage会进入Pi会话统计，不能把工具明细再重复加到同一已知总额。用原始供应方usage事件区分reported和missing；Pi初始化的零值不能证明供应方报告了零用量。V16的缺失用量替身按null和missing记录，费用按预留处理。

V18中，请求钩子throw后仍发出1次请求并得到HTTP200；ctx.abort对照没有调用fetch，也没有HTTP请求。固定SDK路径可用ctx.abort事前取消；不能用抛异常实现预算硬控制。探针预算开关也按此修正：V12新增派发计数断言在原实现失败，修复后实际dispatch为0、stopReason aborted，其他停止路径保持通过。

V27使用20段固定文本，每段1次：英语5段、中文5段、混合10段，长度500至20000字符。输入总量按input加cacheRead加cacheWrite。经验系数为CJK0.889、Latin0.309，另留2048固定开销，样本内估算均不低于实际。该结果只支持这些样本范围，不能当作任意代码、Schema、Unicode输入的普适Token上界。后续V19/V20沿用该配置做预算预留。

费用全书口径须包含整个会话所有分支的实际消费、未知义务与中断预留。P0真实调用使用共享usage-ledger，未知不记零；明确在HTTP前取消、已观测未发出的请求另行计数。V10夹具失败和V19先导也进入同一预算，不因重做而抹去。产品的会话级归因与宏中断可恢复上界仍由P1/P4正式实现。
