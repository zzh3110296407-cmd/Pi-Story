# ADR-014：句子、摘要与行差异

状态：采用。日期：2026-10-28。

sentenceRule=s1保持冻结，执行方案A.1的中英文标点、缩写、小数、引号收尾与不跨段规则。句子位置是LF规范化正文的UTF-16区间，编号按章连续。旧提交和旧草稿继续使用原规则。

2026-10-29作者批准补自然中文与句界规则。新建草稿使用s2，修订草稿继承父草稿的规则，查询证据按提交自带的规则解释，不重编号旧章节。s2在s1基础上增加：

- a.m./p.m.后小写或数字续文不切；后接大写新句仍切。migr./decom.按有限技术缩写词表处理，不声称自动理解所有缩写。
- 句首（包括前句之后）、可选引用符号/强调符号后的数字加点作为列表序号，不单独形成一句。
- 配对的Markdown单/双星号或下划线结束符归入前句；只识别同一行内的配对标记，不实现完整Markdown解析。

DS01 v3新增鲁迅、朱自清六篇有出处的自然中文文本，按作品划分开发/验收部分；自然中文验收430句，独立计算F1，模板样本不能稀释其错误。金标为AI候选，独立ICU候选分句后逐项裁定与s2的差异，并明确标注实现后生成、待人工认可。

摘要是LF规范化正文UTF-8 SHA-256的前16位小写十六进制。行差异用LCS产生目标文本新增/变化行号；等长路径优先消费旧行，保证重复行时结果确定。删除本身没有目标行号，提交资格中的旧证据变化还需比较旧行是否保留。

作者原话两边NFC、全半角ASCII排版统一（U+FF01–U+FF5E映射到ASCII）并合并空白，定位最近匹配消息；不使用广义NFKC，不合并圈号数字或跨文字形似字符。sourceSpans的start/end索引同一规范化消息，quote保留传入原话。原文展示应使用quote，不能把规范化区间直接套在未规范化消息上。DS02 v3对全半角标点和字母采用相同来源标准。

来源匹配只证明引文来源，不证明删去条件后的整理内容获得授权。writer/editor/patch通过authorSources按messageId只收集一次完整sourceText（找不到原作者消息时为null），authorQuotes保留消息引用；author_quotes的authority增加establishes=source_only，直接作者命令仍以author_command为权威。P2必须让角色保留原文条件与否定，不把H05当成语义授权质量证明。

混排字数按汉字数加非汉字词数计，有汉字时unit为zh_chars，否则en_words；连续中英文不需空格也分别计数。对白必须在同一段有成对引号，支持中文嵌套和英文双引号。
