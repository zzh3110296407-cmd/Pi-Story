# ADR-009：主笔候选模型

日期：2026-10-28。状态：P0 样本内采用，正式任务仍需后续评测。

## 背景与选项

V20 在固定 v3 故事状态、两条 ConStory train 提示下，比较 deepseek-flash（low）与 deepseek-v4-pro（high）。使用真实 SDK 和两个探针工具：读取状态、返回预制章节；正文生成质量不在本项范围。最终回复沿用 V19 选择的 JSON 模式。

## 决定

优先将 Flash 作为后续主笔候选。两个模型各五次均完成三个事实回答、恰好一次章节提交、收到 GOAL_REACHED 后正常停止；无无效工具调用和提交后多余写入。Flash 五次估算费用为 0.005619564 美元，Pro 为 0.025655696 美元。本次没有观察到支持 Pro 额外成本的任务差异。

## 依据

证据：`D:\开源\test\pi-Story\p0\runs\V20\2026-10-28T09-05-17-202Z-model\result.json`；同目录 `trials.json`、逐请求输出、事件与会话文件保留全部十次记录。两组各十五次网络请求，合计估算 0.031275260 美元。

## 后果与边界

每模型仅五次、两个背景提示，且读取工具提供明确事实，写作工具返回预制结果。这支持最小工具编排可行，不证明文学质量、长程稳定性或不同思考档位的因果差异。产品仍须在 P4/P5 验证实际工具与守卫；不能将此结果写成模型可靠率为 100%。
